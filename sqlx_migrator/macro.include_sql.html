Macro include_sql

macro_rules! include_sql {
    (up: $up:literal,down: $down:literal $(,)?) => { ... };
    (up: $up:literal $(,)?) => { ... };
    ($up:literal, $down:literal $(,)?) => { ... };
    ($base:literal $(,)?) => { ... };
}
Expand description

Macro for building an operation from SQL files embedded at compile time.

Paths are resolved relative to the file which invokes the macro, the same way include_str! resolves them.

Forms:

  • include_sql!("sql/0001") reads sql/0001.up.sql and sql/0001.down.sql and builds a reversible operation.
  • include_sql!("a.sql", "b.sql") or include_sql!(up: "a.sql", down: "b.sql") builds a reversible operation from explicit files.
  • include_sql!(up: "a.sql") builds an irreversible operation which only has an up step.
ⓘ
sqlx_migrator::postgres_migration!(
    FirstMigration,
    "main",
    "first_migration",
    sqlx_migrator::vec_box![],
    sqlx_migrator::vec_box![
        sqlx_migrator::include_sql!("sql/0001"),
        sqlx_migrator::include_sql!(up: "sql/0001_seed.sql"),
    ]
);
