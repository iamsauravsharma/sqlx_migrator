Migrator module

Migrator plans and runs migrations for Postgres, Sqlite and MySql when the matching feature is enabled. Its configuration, such as table prefix, schema and lock, is a Dialect value which can be adjusted with setters.

§Example

Postgres migrator with no lock

use sqlx::Postgres;
use sqlx_migrator::migrator::LockStrategy;
use sqlx_migrator::{Dialect, Migrator};

let dialect = Dialect::postgres().set_lock_strategy(LockStrategy::None).unwrap();
let migrator = Migrator::<Postgres>::new(dialect);
